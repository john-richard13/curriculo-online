Habilidades técnicas em ação

Nesta seção apresento alguns projetos desenvolvidos durante meus estudos em programação e desenvolvimento web. Cada projeto foi construído com o objetivo de aplicar, na prática, conceitos de lógica de programação, estruturação de páginas web e organização de código, utilizando tecnologias como HTML5, CSS3 e JavaScript. Esses trabalhos representam etapas importantes do meu processo de aprendizado, envolvendo a criação de interfaces, implementação de funcionalidades básicas e utilização de boas práticas de desenvolvimento e versionamento de código com Git e GitHub. Por meio desses projetos, busco consolidar meus conhecimentos técnicos e evoluir continuamente na área de desenvolvimento de software.

Projetos

Sistema de Cadastro

  • Desenvolvimento de aplicação web para cadastro e gerenciamento de clientes, produtos e fornecedores.
  • Estruturação das páginas utilizando HTML5, com organização semântica dos elementos da interface.
  • Implementação de formulários de cadastro para entrada e organização de dados.
  • Estilização da interface utilizando CSS3, com foco em organização visual e usabilidade.
  • Estruturação do projeto em múltiplas páginas e diretórios para melhor organização do código.
  • Utilização de Git e GitHub para versionamento e publicação do projeto.
https://github.com/john-richard13/cadastro-html-css

Jogo do Número Secreto

  • Projeto desenvolvido durante o curso Lógica de Programação da Alura, com foco na aplicação prática de conceitos fundamentais de programação.
  • Desenvolvimento de jogo interativo em JavaScript baseado em tentativa e erro para descoberta de número aleatório.
  • Implementação de estruturas condicionais (if/else) e estruturas de repetição para controle do fluxo do jogo.
  • Criação e utilização de funções em JavaScript para modularização e organização do código.
  • Manipulação de elementos HTML via JavaScript, exibindo mensagens dinâmicas ao usuário.
  • Aplicação de conceitos de algoritmos, variáveis e lógica de programação na construção da mecânica do jogo.
